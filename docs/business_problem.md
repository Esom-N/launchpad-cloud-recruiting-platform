# Business Problem

## Overview

Recruiting teams often manage candidate information across disconnected tools such as spreadsheets, email conversations, and cloud storage folders.

This creates challenges including:

- limited visibility into application progress
- difficulty organizing recruiting documents
- missed deadlines
- inconsistent tracking of interview information


## Problem Statement

Organizations need a centralized workflow solution that can organize recruiting data, securely store documents, and automate repetitive recruiting tasks.


## Project Goal

Launchpad is a cloud-based recruiting workflow platform designed to improve how recruiting information is managed by:

- centralizing application tracking
- organizing recruiting documents
- monitoring important deadlines
- demonstrating how Microsoft Azure services can support business process improvement
